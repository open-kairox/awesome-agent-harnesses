# Hermes Agent

> An open-source, self-hosted AI agent from Nous Research with persistent memory, automated skill creation, multi-platform messaging, and a plugin architecture. MIT licensed. "The agent that grows with you."

## Official Docs & Repos

- [**Hermes Agent — GitHub**](https://github.com/nousresearch/hermes-agent) — The official repo. Python-based, MIT-licensed. Install via `pip install hermes-agent`. Supports 200+ models via OpenRouter, Nous Portal, NovitaAI, NVIDIA NIM, and more.
- [**Hermes Agent — Official Docs**](https://hermes-agent.nousresearch.com/docs/) — Full documentation covering quickstart, configuration, skills, plugins, memory, gateway, and multi-platform messaging.
- [**Hermes Agent — Quickstart**](https://hermes-agent.nousresearch.com/docs/getting-started/quickstart) — Get one clean conversation working first, then layer on gateway, cron, skills, voice, or routing.
- [**Hermes Agent — Product Page (Nous Research)**](https://hermes-agent.nousresearch.com/) — "An autonomous agent that lives on your server, remembers what it learns, and gets more capable the longer it runs." Covers Telegram, Discord, Slack, WhatsApp, Signal, Email, CLI.
- [**Hermes Agent — Community Site**](https://hermes-agent.org/) — Community landing page highlighting persistent memory, automated skill creation, and multi-platform reach.

## Skills & Plugins

- [**Skills System — Official Docs**](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills) — Detailed reference for the skills system: SKILL.md format, lazy loading, config injection, and the `/skills` command interface.
- [**Working with Skills — Guide**](https://hermes-agent.nousresearch.com/docs/guides/work-with-skills) — How to install, configure, and use skills. Covers official optional skills, hub installation, and direct URL installation.
- [**Skills Hub — Official**](https://hermes-agent.nousresearch.com/docs/skills/) — The official skills directory with orchestrator playbooks, Kanban worker guidance, and edge case documentation.
- [**Plugins — Official Docs**](https://hermes-agent.nousresearch.com/docs/user-guide/features/plugins) — Extend Hermes with custom tools, hooks, and integrations via the plugin system.
- [**awesome-hermes-agent — GitHub**](https://github.com/0xNyk/awesome-hermes-agent) — Community-curated list of skills, tools, integrations, and resources. Tags every resource with maturity level. Covers wondelai/skills (380+ stars), litprog-skill, hermes-workspace, and mission-control.
