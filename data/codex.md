# OpenAI Codex CLI

> A coding agent from OpenAI that runs locally in your terminal. Launched April 2025 as Codex CLI, now powered by GPT-5.5-Codex with cloud and desktop surfaces in addition to CLI.

## Official Docs & Repos

- [**Codex CLI — GitHub**](https://github.com/openai/codex) — The open-source repo for Codex CLI. Install via `npm i -g @openai/codex` or Homebrew. Includes full README, configuration docs, and contribution guidelines.
- [**Codex CLI — Official Docs**](https://developers.openai.com/codex/cli) — Developer portal covering CLI commands, subagents, MCP integration, Codex Cloud launch, and the `exec` command for scripting repeatable workflows.
- [**Codex Changelog**](https://developers.openai.com/codex/changelog) — Release-by-release changelog from May 2025 to present. Tracks TUI improvements, plugin workflows, @ mentions, and marketplace CLI commands.
- [**Introducing Codex — OpenAI Blog**](https://openai.com/index/introducing-codex/) — Launch announcement from April 2025. Describes the cloud-based software engineering agent, sandboxed execution environment, and GitHub integration.
- [**Introducing the Codex App — OpenAI Blog**](https://openai.com/index/introducing-the-codex-app/) — Follow-up post covering the desktop app, evolution since CLI launch, and the full software development lifecycle.
- [**Introducing Upgrades to Codex — OpenAI Blog**](https://openai.com/index/introducing-upgrades-to-codex/) — Covers GPT-5-Codex model availability, API key access, and feature expansion.
- [**Codex (AI Agent) — Wikipedia**](https://en.wikipedia.org/wiki/OpenAI_Codex_(AI_agent)) — Good historical overview from Codex CLI launch through GPT-5.5-Codex consolidation.
- [**Codex Blog Posts — OpenAI Developers**](https://developers.openai.com/blog/topic/codex) — All official blog posts tagged with Codex. Includes Figma integration, Agents SDK workflows, and GitHub Actions optimization.
