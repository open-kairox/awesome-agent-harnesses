# Claude Code

> Anthropic's agentic coding tool that lives in your terminal, understands your codebase, and helps you code faster through natural language commands. Available as CLI, IDE extension, SDK, desktop app, and browser.

## Official Docs & Repos

- [**Claude Code — GitHub**](https://github.com/anthropics/claude-code) — The official repo. Agentic coding tool that reads codebases, edits files, runs commands, and integrates with dev tools via natural language.
- [**Claude Code — npm**](https://www.npmjs.com/package/@anthropic-ai/claude-code) — npm package for installation (`npm install -g @anthropic-ai/claude-code`).
- [**Claude Code — Official Docs**](https://code.claude.com/docs/en/overview) — Comprehensive docs covering terminal, IDE, desktop app, and browser surfaces.
- [**Claude Code Best Practices — Official**](https://code.claude.com/docs/en/best-practices) — Tips and patterns from Anthropic for getting the most out of Claude Code, from environment configuration to scaling across parallel sessions.
- [**Claude Code — Product Page**](https://www.anthropic.com/product/claude-code) — Product overview emphasizing safety design: explicit permissions, human oversight, and trust calibration.
