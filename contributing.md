# Contributing to Awesome Agent Harnesses

Thank you for your interest in contributing! This is a curated list, so we have a few guidelines to keep things organized and useful.

## How to Contribute

1. **Fork** the repository
2. **Add your resource** to the appropriate section in `README.md` or the relevant `data/*.md` file
3. **Open a Pull Request** with a clear description of what you're adding

## What We're Looking For

- Official documentation and repos
- Blog posts and tutorials (high-quality, not SEO spam)
- Community resources (Discord servers, forums, subreddits)
- Plugins, extensions, and skills
- Conference talks and video presentations
- Example projects and templates
- Release notes and changelogs

## Formatting

Each resource entry should follow this format:

```
- [**Resource Title**](URL) — 2-3 sentence summary of what it covers and why it's useful.
```

Example:
```
- [**Getting Started with Claude Code**](https://docs.anthropic.com/en/docs/claude-code) — Official quickstart guide covering installation, configuration, and first steps. Good entry point for developers new to agentic coding tools.
```

## Quality Standards

- Links must be live and accessible
- Summaries must be accurate and useful (not marketing copy)
- Prefer primary sources over secondary coverage
- No affiliate links or sponsored content
- Resources should be relevant to developers using or building with agent harness CLIs

## Adding a New Harness

If you want to add a new harness CLI to the list, please:

1. Check existing issues/PRs to avoid duplicates
2. Ensure the tool meets the criteria in "What is an Agent Harness?" in the README
3. Add entries to both `README.md` and create a new `data/harness-name.md`
4. Include at minimum: official repo, docs, and 3 community resources
